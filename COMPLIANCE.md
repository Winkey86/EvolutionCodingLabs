Заявка подготовлена до реализации, пользователь согласовал реализацию предложенной темы. Это не равнозначно утверждению преподавателем.

```text

```

## Автоматическая проверка

```bash
python3 verify.py
python3 -m unittest test_dispatch -v
```

Скрипт проверяет вариант и формулу HGBat, число запусков, равенство бюджетов, комплектность ссылок, валидность SVG, масштаб данных и ограничения лучшего меню. Для ЛР3–ЛР4 заново вычисляет тестовое качество каждой сохранённой модели, сводную статистику, validation выбранной модели и предметное расписание. Тесты независимо проверяют расчёт симулятора на ручном примере, корректность операторов, отсутствие информации о будущей длительности, фактическое число оценок и воспроизводимость эволюции.
