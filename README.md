# Эволюционное программирование и генетические алгоритмы

Лабораторные работы №1–№4 для группы **517**, номер в списке **18**, вариант **20**. Реализация на Python 3.10+ без сторонних зависимостей. Код, входные данные, отчёты и результаты экспериментов находятся в репозитории.

Для ЛР4 подготовлены заявка и реализация собственной темы. Утверждение темы преподавателем и устная защита остаются внешними условиями; программная готовность их не заменяет.

## Проверка варианта

По формуле из методических указаний

```text
V = 1 + ((17N + 7Q + Y) mod 20),
```

где `N=18`, `Q=1` для группы 517 и `Y=26` для 2026 года:

```text
V = 1 + ((17·18 + 7·1 + 26) mod 20)
  = 1 + (339 mod 20)
  = 20
```

## Быстрый запуск

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/Winkey86/EvolutionCodingLabs.git
cd EvolutionCodingLabs

(cd lab_1_hgbat && python3 main.py)
(cd lab_2_weekly_menu && python3 main.py)
python3 lab_3_dispatch_gp/main.py
python3 lab_4_robust_dispatch/main.py
```

ЛР1–ЛР3 выполняют по 20 независимых запусков каждой конфигурации, ЛР4 — по 30. Программы обновляют результаты в своих папках `results/`; все seed и параметры сохранены. ЛР3 и ЛР4 используют общие корневые модули, поэтому сохраняйте структуру репозитория.

Для автоматической проверки комплектности и ключевых требований:

```bash
python3 verify.py
python3 -m unittest test_dispatch -v
```

Подробная матрица «требование → доказательство» приведена в [COMPLIANCE.md](COMPLIANCE.md).

## Лабораторная №1 — HGBat

Минимизируется функция

```text
f(x) = √|(Σxᵢ²)² − (Σxᵢ)²| + (0.5Σxᵢ² + Σxᵢ)/d + 0.5,
d = 7,  −15 ≤ xᵢ ≤ 15.
```

Глобальный минимум: `xᵢ = −1`, `f(x*) = 0`. Реализованы турнирная селекция, BLX-α-кроссовер, гауссовская мутация, обработка границ и элитизм. Две настройки мутации сравниваются со случайным поиском при одинаковом бюджете 12 000 вычислений функции.

## Лабораторная №2 — меню на неделю

Особь содержит 21 индекс блюда: завтрак, обед и ужин для каждого из семи дней. Ограничения:

- 1700–2200 ккал в сутки;
- недельная стоимость не более 3800;
- не менее 15 различных блюд;
- каждое блюдо используется не более двух раз.

Сравниваются ремонт допустимости и штрафная функция, равномерный и одноточечный кроссоверы, а также случайный допустимый поиск с тем же бюджетом оценок. Во всех 20 запусках каждой конфигурации найдено допустимое меню.

## Воспроизводимость

- Генераторы случайных чисел используют фиксированные `seed`.
- Для каждой конфигурации ЛР1–ЛР3 выполнено 20 независимых запусков; для каждого метода ЛР4 — 30.
- CSV содержат исходные данные, результаты запусков и агрегированную статистику.
- Алгоритмические операторы реализованы вручную; библиотеки оптимизации не используются.

## Лабораторные №3 и №4 — распределение задач

В ЛР3 генетическое программирование синтезирует выражения приоритета назначения. Ограниченный язык, операторы поддеревьев и штраф сложности сохраняют корректность и компактность программ. Отдельные train/validation/test сценарии позволяют отличать обучение от проверки. В архиве показаны три эволюционировавшие программы разной сложности.

В ЛР4 число задач увеличено до 48, длительности имеют сценарную неопределённость, качество учитывает средние потери и разброс. Локальные пробы меметического алгоритма входят в те же 640 обучающих оценок, что и у базового GP. Фактические длительности недоступны политике при назначении.
