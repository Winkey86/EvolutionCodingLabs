# ЛР3 — синтез правил распределения задач

Группа **517**, номер **18**, вариант **20**, **трек B**.

Генетическое программирование строит выражение приоритета назначения задач пяти неоднородным исполнителям. Исследуются качество и сложность программ при предельных глубинах 1, 2 и 4. Каждая конфигурация проходит 20 независимых запусков; используются отдельные train, validation и test сценарии.

## Запуск из корня репозитория

Нужен Python 3.10+, внешних зависимостей нет.

```bash
python3 lab_3_dispatch_gp/main.py
python3 -m unittest test_dispatch lab_3_dispatch_gp.test_report -v
python3 verify.py
```

Пути вычисляются относительно скрипта: программа также запускается командой `python3 main.py` из этой папки. Общий код находится в корневых `dispatch_core.py` и `dispatch_experiments.py`, поэтому папку следует сохранять в составе репозитория.

```bash
python3 lab_3_dispatch_gp/main.py --runs 20 --budget 480
```

`--runs` не меньше 20; бюджет не меньше популяции 32. Можно указать отдельную папку `--output`. При изменении параметров результаты относятся к новой серии; штатный валидатор проверяет стандартную сдаваемую серию.
