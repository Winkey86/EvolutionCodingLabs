# Эволюционное программирование — лабораторные №1 и №2

Студент: номер в списке **16**, группа **517**, индивидуальный вариант **6**.

- Лабораторная №1: минимизация функции Швефеля генетическим алгоритмом, `d=5`, `x_i ∈ [-500, 500]`.
- Лабораторная №2: генетический алгоритм для плана закупки расходных материалов при ограниченном бюджете и минимальных запасах; особь представлена целочисленным вектором.

Код, инструкция запуска, отчёты, исходные данные, результаты 20 независимых запусков и графики находятся в каталоге [`labs_1_2_list16`](labs_1_2_list16/README.md).

## Запуск

```bash
cd labs_1_2_list16
python3 run_all.py --group 517
```

Проект использует только стандартную библиотеку Python 3.
