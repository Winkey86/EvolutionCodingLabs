# Лабораторная работа №2 — план закупки расходных материалов

Вариант **6**, группа 517, номер в списке 16.

## Задание

Составить месячный план закупки не менее чем для 30 видов расходных материалов при:

- ограниченном бюджете;
- обязательном минимальном запасе каждого материала;
- целочисленном количестве единиц;
- максимизации суммарной полезности закупки.

Особь — целочисленный вектор из 30 количеств.

## Запуск

```bash
python3 main.py
```

Программа детерминированно создаёт `data/materials.csv`, выполняет 20 независимых запусков каждой конфигурации и записывает отчёт, статистику, лучший план и график в `results/`.

Дополнительные параметры:

```bash
python3 main.py --runs 20 --generations 180 --output results
```

Сторонние пакеты не требуются.
