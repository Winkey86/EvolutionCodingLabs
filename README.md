# Эволюционное программирование — лабораторные №1 и №2

Группа **517**, номер в списке **16**, осенний семестр 2026 года.

## Проверка варианта

По методическим указаниям:

```text
N = 16
Q = 1  (группа 517)
Y = 26 (2026 год)
V = 1 + ((17N + 7Q + Y) mod 20)
  = 1 + ((17·16 + 7·1 + 26) mod 20)
  = 1 + (305 mod 20)
  = 6
```

Следовательно, без отдельного переназначения преподавателем выполняется **вариант 6**.

## Работы

- [`lab_1_schwefel`](lab_1_schwefel/README.md) — вещественный генетический алгоритм для минимизации функции Швефеля, `d=5`, `xᵢ ∈ [-500, 500]`.
- [`lab_2_procurement`](lab_2_procurement/README.md) — дискретный генетический алгоритм для месячного плана закупки расходных материалов при ограниченном бюджете и минимальных запасах.

Обе папки самостоятельны и используют только стандартную библиотеку Python 3. В каждой находятся код, инструкция, отчёт, исходные данные, результаты 20 независимых запусков и SVG-график.
