# Лабораторная работа №2 — меню на неделю

Вариант **20**, группа 517, номер в списке **18**.

## Задание

Сформировать меню на семь дней с тремя приёмами пищи в день при ограничениях:

- суточная калорийность — от 1700 до 2200 ккал;
- недельная стоимость — не более 3800 условных единиц;
- не менее 15 различных блюд за неделю;
- одно блюдо используется не более двух раз;
- максимизируется суммарная оценка блюд.

Особь — целочисленный вектор из 21 индекса блюда.

## Запуск

```bash
python3 main.py
```

Программа создаёт воспроизводимый набор из 36 блюд, выполняет 20 независимых запусков каждой конфигурации и записывает отчёт, статистику, лучшее меню и график в `results/`.

```bash
python3 main.py --runs 20 --generations 180 --output results
```

Сторонние пакеты не требуются.
