# ЛР4 — устойчивые правила распределения задач

Группа **517**, номер **18**, вариант **20**: собственная прикладная задача. Тема предложена пользователем к реализации; подтверждение утверждения преподавателем отсутствует. [Заявка](PROPOSAL.md) подготовлена до основной реализации. Для формального закрытия ЛР4 требуется утверждение темы и защита.

Исследуется назначение 48 задач пяти неоднородным агентам при неопределённой длительности. Базовое генетическое программирование сравнивается с меметическим: локальные пробы входят в тот же бюджет. Выполняются 30 независимых запусков каждого метода, затем проверка на отложенных сценариях.

## Запуск из корня репозитория

Python 3.10+, внешних зависимостей нет.

```bash
python3 lab_4_robust_dispatch/main.py
python3 -m unittest test_dispatch -v
python3 verify.py
```

Пути вычисляются относительно скрипта; допустим запуск `python3 main.py` из этой папки. Требуются общие корневые модули `dispatch_core.py` и `dispatch_experiments.py`.

```bash
python3 lab_4_robust_dispatch/main.py --runs 30 --budget 640
```

`--runs` не меньше 30; бюджет не меньше популяции 32. Для отдельного эксперимента доступен `--output`.
