# Проверка соответствия методическим указаниям

Проверка выполнена по документу «Эволюционное программирование и генетические алгоритмы. Комплекс лабораторных работ» для группы 517, номера в списке 18.

## Индивидуальный вариант

```text
V = 1 + ((17·18 + 7·1 + 26) mod 20) = 20
```

## Общие требования

| Требование | Выполнение и доказательство |
|---|---|
| Самостоятельная реализация операторов | Селекция, кроссовер, мутация, элитизм и обработка ограничений реализованы в `main.py`; библиотек оптимизации нет |
| Фиксированные seed и независимые запуски | Seed каждого запуска записан в `results/runs.csv`; число запусков задаётся `--runs`, минимум — 20 |
| Читаемый функционально разделённый код | Обе работы разделены на функции генерации, оценки, операторов, эксперимента и экспорта |
| Инструкция запуска | README каждой лабораторной содержит команду запуска и параметры CLI |
| Воспроизводимость | Исходные данные, параметры, результаты и скрипт `verify.py` находятся в репозитории |
| Отчёт | В каждой папке есть `results/REPORT.md` с постановкой, представлением, алгоритмом, блок-схемой, параметрами, статистикой, анализом и выводом |
| Таблица параметров | `results/parameters.csv` |
| Машиночитаемые результаты | `results/runs.csv` и `results/summary.csv` |
| Не менее 20 запусков | ЛР1: 20 запусков каждого из трёх методов; ЛР2: 20 запусков каждого из четырёх методов |
| Статистика | Лучшее, среднее, медиана, стандартное отклонение и худшее приведены в отчётах и `summary.csv` |

## Лабораторная работа №1

| Требование | Выполнение и доказательство |
|---|---|
| Вариант 20, HGBat | Формула реализована функцией `hgbat`; `hgbat([-1] * 7) == 0` |
| Размерность | `d = 5 + (20 mod 6) = 7` |
| Область | Каждая координата находится в `[−15, 15]` |
| Вещественное кодирование | Особь — список из семи вещественных координат |
| Популяция не менее 30 | Размер популяции — 60 |
| Допустимая инициализация | Равномерная генерация внутри области |
| Селекция | Турнир размера 3 |
| Вещественная рекомбинация | BLX-α, `α=0.35` |
| Вещественная мутация | Гауссовская мутация |
| Обработка границ | Отсечение координат до `[−15, 15]` |
| Элитизм | Одна лучшая особь переносится без повторной оценки |
| Критерий остановки | Ровно 12 000 вычислений функции |
| Две конфигурации, один изменяемый фактор | Отличается только масштаб мутации: 2% и 8% ширины области |
| Базовый метод с равным бюджетом | Случайный поиск, также 12 000 оценок |
| График серии запусков | `convergence.svg`: минимум, среднее и максимум лучшего значения по поколениям |
| Дополнительный оператор | Реализован BLX-α-кроссовер |

## Автоматическая проверка

```bash
python3 verify.py
```

Скрипт проверяет вариант и формулу HGBat, число запусков, равенство бюджетов, комплектность файлов и ссылок, валидность SVG, масштаб данных и все ограничения лучшего недельного меню.
