# Лабораторная работа №1 — функция Швефеля

Вариант **6**, группа 517, номер в списке 16.

## Задание

Найти приближённый глобальный минимум функции

```text
f(x) = 418.9829·d − Σ xᵢ·sin(√|xᵢ|),  i=1..d
d = 5,  −500 ≤ xᵢ ≤ 500.
```

Известный минимум находится около `xᵢ = 420.968746` и равен примерно нулю.

## Запуск

```bash
python3 main.py
```

Программа выполняет 20 независимых запусков двух конфигураций ГА и случайного поиска при одинаковом бюджете в 12 000 вычислений функции. Результаты записываются в `results/`.

Дополнительные параметры:

```bash
python3 main.py --runs 20 --evaluations 12000 --output results
```

Сторонние пакеты не требуются.
