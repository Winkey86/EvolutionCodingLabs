# Лабораторные работы №1 и №2 — номер в списке 16

Решение написано на Python 3 и не требует сторонних пакетов.

## Какой вариант делать

В методичке указано:

```text
V = 1 + ((17N + 7Q + Y) mod 20)
```

Здесь `N=16`, `Y=26`, а `Q` зависит от группы.

| Группа | Q | Вариант V | ЛР1 | d | ЛР2 |
|---:|---:|---:|---|---:|---|
| 507 | 0 | 19 | HappyCat («счастливая кошка»), `[-20,20]^6` | 6 | Расписание экзаменов с конфликтами студентов |
| 517 | 1 | 6 | Schwefel (Швефеля), `[-500,500]^5` | 5 | План закупки расходных материалов |
| 527 | 2 | 13 | Salomon (Саломона), `[-100,100]^6` | 6 | Маршрут сбора отходов с ограничением грузоподъёмности |

Проверить расчёт:

```bash
python3 variant.py
```

## Запуск

Из этой папки выполните команду, подставив свою группу:

```bash
python3 run_all.py --group 507
```

По умолчанию выполняются требуемые 20 независимых запусков. Для групп 517 и 527 замените номер группы. Результаты появятся в `results/`: отчёты Markdown, CSV с каждым запуском и статистикой, исходные данные, лучшие решения и SVG-графики.

Отдельный запуск:

```bash
python3 lab1.py --group 507 --runs 20
python3 lab2.py --group 507 --runs 20
```

## Что реализовано

- ЛР1: вещественный ГА, турнирная селекция, BLX-α, гауссовская мутация, отсечение по границам, элитизм; две конфигурации одного параметра; случайный поиск при равном бюджете; 20 запусков; статистика и график сходимости.
- ЛР2: дискретное представление, специализированные операторы, штрафы и восстановление допустимости, сравнение операторов, 20 запусков, два допустимых и два недопустимых примера, конструктивная базовая эвристика, CSV лучшего решения и график.

Все генераторы данных и эксперименты используют фиксированные `seed`, поэтому результаты воспроизводимы.
