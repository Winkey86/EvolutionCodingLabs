# Лабораторная работа №1

## Вариант

- Номер в списке: 16.
- Группа: 517.
- Формула: `V = 1 + ((17·16 + 7·Q + 26) mod 20)`.
- Вариант: **V=6**, функция **Schwefel (Швефеля)**.
- Размерность: `d = 5 + (V mod 6) = 5`.
- Область поиска: `[-500.0, 500.0]^5`.
- Известный глобальный минимум: `f(x*) = 0.0` при `x_i = 420.968746`.

## Алгоритм

Особь — вещественный вектор длины 5. Использованы турнирная селекция (размер 3), BLX-α-кроссовер (`α=0.35`), гауссовская мутация, отсечение координат по границам и элитизм одной особи. Бюджет каждой попытки — 12000 вычислений функции, популяция — 60.

Сравниваются две конфигурации, отличающиеся только масштабом мутации: 5% и 15% ширины области. Базовый метод — равномерный случайный поиск при том же бюджете.

## Вывод

Функция Schwefel (Швефеля) нетривиальна для локального/случайного поиска: её ландшафт имеет выраженную нелинейность и/или множество локальных структур, а объём пространства экспоненциально растёт с размерностью. Генетический алгоритм использует накопленную популяцией информацию; сравнение с `random_search` показывает, насколько это полезно при одинаковом числе обращений к функции. Различие между масштабами мутации демонстрирует компромисс между локальным уточнением и выходом из областей притяжения.
