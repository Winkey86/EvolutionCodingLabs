## Быстрый запуск

Требуется **Python 3.10 или новее**. Внешние пакеты не нужны.

```bash
git clone https://github.com/Winkey86/EvolutionCodingLabs.git
cd EvolutionCodingLabs

# Лабораторная №1
(cd lab_1_schwefel && python3 main.py)

# Лабораторная №2
(cd lab_2_procurement && python3 main.py)
```

Каждая команда заново выполняет обязательные серии из 20 независимых запусков и обновляет свою папку `results/`.

## Почему вариант 6

В методических указаниях используется формула

```text
V = 1 + ((17N + 7Q + Y) mod 20),
```

где `N=16`, `Q=1` для группы 517 и `Y=26` для 2026 года:

```text
V = 1 + ((17·16 + 7·1 + 26) mod 20)
  = 1 + (305 mod 20)
  = 6
```

Расчёт считается действующим, если преподаватель отдельно не переназначил вариант.

## Лабораторная №1 — функция Швефеля

Минимизируется функция

```text
f(x) = 418.9829·d − Σ xᵢ·sin(√|xᵢ|),  i=1..d,
d = 5,  −500 ≤ xᵢ ≤ 500.
```

Реализованы турнирная селекция, BLX-α-кроссовер, гауссовская мутация, обработка границ и элитизм. Проведено сравнение двух масштабов мутации и случайного поиска при одинаковом бюджете в 12 000 вычислений функции.

## Лабораторная №2 — план закупок

Для 30 материалов подбираются целочисленные количества, максимизирующие полезность при ограниченном бюджете и обязательных минимальных запасах.

Сравниваются ремонт допустимости и штрафная функция, а также равномерный и одноточечный кроссоверы. В качестве базовых методов используются случайный допустимый поиск с тем же бюджетом оценок и жадная конструктивная эвристика. Все лучшие решения в серии допустимы.
